# RISC-V-RV32I-Single-Cycle-CPU-
Architected a synthesizable RISC-V RV32I CPU via Vivado.  Developed and integrated modular components including the ALU, register file, and control logic. Validated architectural integrity by developing comprehensive Verilog testbenches to simulate and verify the execution of arithmetic (ADD/SUB), memory (LW/SW), and control-flow (BEQ/JAL) o/p.
